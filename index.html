Under the surface

One search. Many systems.

The internet is not a cloud. It is routers, data centers, radio, glass fiber, and carefully coordinated rules.

01

Local network

Wi‑Fi turns frames into radio waves. Your router forwards them to your internet provider.

  • ARP finds the gateway
  • Wi‑Fi protects the local frame
  • NAT may replace the private IP
02

DNS & routing

DNS translates names into IP addresses. Routers then choose the next useful hop—not one fixed path.

  • Cache is checked first
  • TTL controls reuse time
  • BGP connects networks
03

Across the ocean

Lasers carry data through hair-thin glass fibers protected inside cables laid along the seabed.

  • Cable ships survey the route
  • Repeaters restore the signal
  • Shore ends are buried and armored
04

Server & return

An edge or origin server processes the request. TCP checks delivery, then your browser rebuilds the response.

  • CDNs cache nearby copies
  • TCP orders and retries data
  • The return path may differ

What this can—and cannot—show. Live mode plots every responding public router using its measured IP. Traceroute cannot reveal the exact submarine cable, so long ocean spans use clearly marked landing-station models. IP location is approximate, private hops may be hidden, and the return route can differ.
